# 🃏 솔리테어 (Klondike Solitaire)

모바일 웹에서 플레이 가능한 클론다이크 솔리테어.

## 특징

- 📱 **모바일 최적화** — 터치 드래그 & 탭으로 조작
- 🤖 **오토플레이** — 버튼 하나로 AI가 최선의 수를 자동으로 둠
- ↩️ **되돌리기** — 최대 50수까지 undo
- ⏱️ **타이머 & 이동 카운터** — 실적 추적
- 🎨 **Canvas 기반 렌더링** — 부드러운 카드 UI

## 조작법

| 동작 | 방법 |
|------|------|
| 카드 뒤집기 | 스톡(왼쪽 위) 탭 |
| 카드 이동 | 드래그 & 드롭 |
| 파운데이션 이동 | 카드 탭 (자동 감지) |
| 오토플레이 | 🤖 버튼 탭 |
| 되돌리기 | ↩️ 버튼 탭 |

## 실행

```bash
npm start
# http://localhost:3458
```

## 오토플레이 AI 전략

1. 파운데이션에 안전하게 올릴 수 있는 카드 우선
2. 뒤집힌 카드를 드러내는 이동 탐색
3. 웨이스트에서 타블로로 이동
4. 킹을 빈 자리로 이동 (숨겨진 카드 위에 있을 때만)
5. 스톡에서 카드 뒤집기
6. 모든 카드가 앞면일 때는 무조건 파운데이션으로

## 기술 스택

- Vanilla JavaScript (ES Modules)
- Canvas 2D API
- Pointer Events API (터치 + 마우스 통합)
- 외부 의존성 없음 (Zero dependencies)
